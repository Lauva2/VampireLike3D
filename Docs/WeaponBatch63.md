# 第二批武器差异化

> 后续弩、回旋刃、寒霜法杖的实现与最新同版九武器回归见[第三批记录](WeaponBatch64.md)；下方63版证据保留为历史范围。

2026-10-23用户要求继续下一步，承接首批手枪/火球/飞剑，本批实现灵体、爆破炮和符阵。弩、回旋镖、冰杖维持原攻击类型。

## 行为

- 灵体：持续跟随的召唤物，蓄势后扑击有效目标，命中一次后无伤回位。spiritcount与通用数量增加逻辑召唤数量；spiritdamage保持原伤害增幅，spiritspeed影响调度频率并加快扑击。目标按CollisionId校验，出射或追击时失效会重新索敌，不追逐射程外目标。
- 爆破炮：最多0.35秒装填，然后高抛炮弹；飞行中不伤害敌人，落地时统一结算3.3米基础范围爆炸。cannoncount增加不同落点，cannonradius扩大真实爆炸半径。金色友方落点圈与敌方红色预警区分，圈大小对应伤害范围；预测移动目标落点，突然转向仍可使炮弹落空。
- 符阵：原地展开0.3秒后脉冲，阵纹留在施放位置。每层叠阵使总伤害按原值增加35%，并追加一次脉冲；相邻脉冲间隔0.2秒，阵域与攻速沿用原升级。玩家可以离开阵纹，已展开的阵继续结算。

## 所有权与兼容

三种行为加入既有WeaponAttack调度。灵体复用既有AA武器模型，额外模型由SpiritAttack拥有；第一只模型由AbilityController原有visual集合拥有。灵体模型挂在局根，避免角色移动或转身带动已出击灵体；由行为管理跟随与原点偏移。符阵的临时阵纹使用TransientEffect显式托管模式并由RuneAttack释放；炮弹独占静态mark预制体作为落点圈，在归池或取消时同步归还。静态标记没有TransientEffect组件，不能调用瞬时特效初始化；随浮动原点由炮弹移动，符阵缓存中心和召唤蓄势位置也需同步。

PoolService.Clear先使登记表失效再销毁对象，避免炮弹OnDisable归还附属落点圈时修改正在遍历的对象集合。TransientEffect每次初始化和停用重置托管状态，普通特效仍按原计时到期。GameManager保持整体清理所有权，AA加载与释放路径未改变，无新预制体或旧GUID改动。

视觉预算为最多8只灵体模型、每次最多16枚炮弹、最多6个符阵脉冲阶段；未限制逻辑数量或强化等级。超出模型预算的召唤按伤害权重聚合，忙碌灵体把新的出击权重并入后续有效扑击，避免无界排队。脉冲预算保留原总伤害增幅。该聚合不等同于逐个独立目标、独立暴击的无限实体模拟，需要继续平衡和性能评估。

升级ID、数值配置、任务条件和存档版本保留；将灵弹增殖改名灵体增殖并更新对应说明。旧文件/生成器保持一致。
