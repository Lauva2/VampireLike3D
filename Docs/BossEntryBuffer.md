# Boss 交互与出场缓冲

2026-10-23用户反馈：交互后Boss立刻出现，玩家在交互点附近立即掉血。原Boss虽然有首个技能的冷却，但EnemyActor的2米接触伤害在生成首帧就生效。

## 改动

- CombatWorld收到交互后保留唯一挑战请求，先显示2秒无伤害的召唤提示，倒计时结束才生成Boss。重复交互不会重置倒计时或增加实例。
- Boss生成后用1秒逐渐显现的出场动作；这段时间不移动、不接触伤害、不释放技能、不接受伤害，自动索敌过滤此阶段。出场结束恢复接触伤害；首个技能再等待0.75秒，之后仍按原招式进行预警。
- 暂停冻结上述游戏时钟；召唤中也能离开25米范围，经过2秒缓冲取消挑战。延迟生成使用随浮动原点更新的中心；世界在召唤期保留挑战地点。
- 资源缺失时清除请求并允许重试；返回菜单清除请求，不通过协程在旧局结束后生成。未改玩家全局无敌、Boss伤害、战利品或解锁规则。
- HUD显示召唤倒计时/正在现身；现有诊断先等待出场完成再操作Boss，后台自然流程在召唤时开始绕开中心。
