# 飞剑曲线、环绕朝向与持续剑雨

2026-10-26用户要求：追击飞剑从玩家身上沿贝塞尔曲线飞向敌人；修正环绕方向；剑雨在目标位置先建圆圈，再持续从天落剑，持续一段时间后消失。此记录优先于62/64版单次突刺与瞬时剑雨说明。

## 行为与所有权

- 追击飞剑从玩家约1.4米高的身侧出发，保留0.16秒出剑准备，然后沿三次贝塞尔曲线向左右展开并汇向目标。终点随当前敌人移动，剑尖朝曲线切线；贯穿/弹射后的新目标建立新曲线，返航仍无伤。目标按CollisionId验证，对象复用不能继承锁定；曲线控制点随浮动原点偏移，普通池初始化清空曲线状态。
- 绕身剑模型的剑尖轴是本地+Y，旧Yaw/Roll设置使剑尖接近绕行反向。现在将本地+Y对齐圆周运动切线，剑身平铺，剑尖朝前绕行；维持现有圆周运动速度、半径与伤害。角色转身不会改变最终世界朝向，暂停冻结。
- 剑雨每次在一个有效优先目标的位置部署固定剑域，基础半径3米。圆圈展开0.2秒后，每0.3秒一波，共10波；每波从圈内约8米高处下落，落点按确定性角度分布，目标离开或被复用后不追踪。最后一波落地后圆圈淡出，整体3.5秒结束。每波总基础伤害暂定飞剑伤害的0.3倍，再乘逻辑数量，实际命中仍按落剑轨迹和落地小范围结算；未作整体平衡验收。

通用数量和飞剑增殖影响每波总伤害及显示数量，最多16个显示实例、超出按伤害/灼烧权重保留。基础每波用3柄较轻的落剑表现持续覆盖，升级后增加剑数与权重。贯穿强化继续影响落地伤害半径，范围强化扩大剑域，剑气/烈焰飞剑继续参与。追击、环绕、剑雨同时存在，无槽位或互斥限制。

调度周期沿用5秒并受攻速影响；由此前对最多12个目标各作一次落剑，改为每次选择一个目标的持续区域，伤害时序和覆盖均改变。玩家可通过走位把敌人引入已展开剑域。圈由SwordAttack显式拥有，复用已有AA `vfx/rune` 的托管TransientEffect；落剑归现有投射物池，普通到期回收。取消攻击对象释放圈并清空未来波次，已经下落的剑可自然完成；返菜单由GameManager释放全部本局对象及资源。没有新增预制体或修改既有GUID，升级ID和存档格式不变。
