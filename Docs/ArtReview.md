## 2. 评审纪律与证据要求

1. 总分 100，采用整数计分；最终必须达到 **91 分或更高**。90 分整不通过。评审人必须独立看图或查看运行证据，不接受实现者自报分数。
2. 未见证据记“未验证”，不擅自给满分或把未知当作通过。证据不足时可以报已观察部分的暂评分，但不得换算为完整成品得分。
3. 只评分真实游戏中可达的内容。最终须提供带版本标识的 Windows Player 实机证据；Editor Game View 可用于迭代，概念图、界面设计图、离线渲染和编辑器场景视图不得冒充实机。
4. 截图保留原始尺寸、完整 UI 和实际画幅，禁止选择性裁掉问题区域。成片概览、近景和压力场景都需覆盖。宣传构图不能代替正常游玩视角。
5. 每项扣分必须关联截图编号、录像时码或实际观察步骤，并给出具体修改方向；每项给分也要注明证据。不得通过重命名标准、删掉未完成内容或改变分母来过线。
6. 不要求手工建模而排斥程序化制作，但基础几何体必须经过完整造型、材质、层次和反馈设计。未处理的胶囊人、方块怪、纯色平面、默认按钮和文字堆叠属于占位内容，不能按成品完成度计分。
7. 完整首发内容都纳入评审。只改善首屏、单一群系或空场景不能完成美术验收。新版本修复后使用同一量表复评，并回归受影响页面和战斗场景。

## 4. 不可用高分抵消的通过门槛

最终同时满足以下条件才可记录“美术通过”：

- 总分至少 91/100；A≥13、B≥13、C≥18、D≥18、E≥18、F≥8；任何子项不得低于 4 分。
- 所有已冻结首发角色、四个群系、四 Boss、混合地图、全部正式 UI 均有实机覆盖，无未评分内容。
- 无占位角色/敌人/场景/默认 UI 混入正式内容；无粉色材质、丢失贴图或明显破损模型。
- 中文无缺字方框、关键文字裁切、按钮不可读、遮罩错误、核心 UI 在要求分辨率中出界。
- 密集战斗和 Boss 战中仍能持续定位玩家与敌方危险；不能依赖停止发射、删除已获得能力或关闭实际伤害来制造干净截图。
- 所有 Boss 危险攻击有可辨的前摇/预警；闪避无敌窗口有对应表现。遮挡导致玩家持续不可见、特效掩盖攻击范围或预警与伤害严重错位均直接阻断。
- 动画与反馈有连续证据；不能用单张静止姿态代表完整动画验收。
- 最终证据来自同一可追溯候选版；跨版本拼凑画面不能形成最终通过结论。

本门槛不会因迭代次数较多或项目时间不足而放宽。每轮达标只针对该轮明确的范围，局部达标不代表完整成品通过。
