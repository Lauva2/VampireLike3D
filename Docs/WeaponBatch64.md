# 第三批武器差异化

2026-10-23承接用户“下一步”，实现弩、回旋刃、寒霜法杖。九种武器均由独立WeaponAttack负责出手方式，AbilityController只调度并管理共享数值、分支与资源生命期。

## 实现

- 弩最多拉弦0.32秒（攻速提高同步缩短），然后发射高速平行箭道；基础可贯穿两个目标，已有数量、贯穿、弹射、淬霜强化可同时存在。
- 回旋刃短暂抬手，沿两段弧线穿过出手时的目标位置，再飞至原射程终点。回程沿原弧线叠加当前玩家位置偏移，因此走位影响覆盖；去返各按敌人CollisionId命中一次。无障碍时回收到玩家当前位置；碰到场景障碍会提前归池。目标移动可避开已投出的刃，属于实际轨迹行为。原数量、伤害、攻速、射程、电弧仍适用。
- 寒霜法杖在0.12/0.30/0.48/0.66秒喷出四段扇形寒气；跟随玩家位置，方向固定为本次施法朝向，每段占总伤害四分之一。每次基础接触积累0.35寒冷，三段冻结；深寒一级增加0.15，可两段冻结。冻结时长沿用普通怪1.4秒/Boss0.3秒，实际冻结才计入累计任务。碎霜领域对已冻结目标仍加60%伤害，因此基础完整四段有最后一段碎冰。

寒气的基础射程由旧冰晶18米改为8米、基础半角32度；旧扩张每级增加0.7米及半角5.6度，数量每级增加一份总伤害和半角2度，半角最多65度。寒冷停止接触2秒失效，敌人对象复用不会继承。普通武器概率冻结不改。

保留升级ID、任务和存档格式，同步现有GameCatalog与ExpansionContent生成器说明。弩/回旋刃每次最多16个显示实例，超出数量按伤害权重聚合；寒气以伤害权重表达数量，不丢弃已获得伤害。该预算并非逐个独立目标和独立暴击的无限实体模拟，覆盖与节奏仍需后续平衡。

AA加载、资源租约与PoolService归还路径不变，复用现有已登记资源；没有新增预制体或修改既有GUID。回旋曲线缓存随浮动原点移动；寒气只缓存朝向，不缓存原点，返菜单由GameManager清理攻击对象和池。

## 验证记录

最终开发构建成功，330项编辑器检查通过。后台Player使用独立诊断存档、程序化输入、Camera.Render原始捕获，不操作用户桌面。

测试范围包括弩的蓄力/暂停/贯穿/弹射/冰冻/数量/攻速/旧目标、弧线往返/移动回程/电弧/原点/池重用、寒气角度/范围/分段伤害/积冷/碎冰/过期/遮挡/取消，以及九武器混搭和返菜单AA租约恢复。本轮不进行评分、性能长测或整体成品验收。

首轮Artifacts/WeaponBatch64的原Player496退出1，79项通过，唯一失败为多刃分列后仍按Z轴投影断言19米射程。分列会改变方向，Z分量小于实际平面距离；测试改为检查缓存终点与玩家位置的平面距离，不改变回旋刃行为。旧失败证据保留，重新构建后使用全新目录，不覆盖历史结果。
