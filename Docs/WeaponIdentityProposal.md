# 武器攻击差异化提案

2026-10-23：用户反馈大量武器像同一种发射方式，随后授权分批修改。首批手枪、火球和飞剑见[首批记录](WeaponIdentity62.md)，第二批灵体、爆破炮、符阵见[第二批记录](WeaponBatch63.md)，第三批弩、回旋刃、寒霜法杖见[第三批记录](WeaponBatch64.md)。下表为原提案，实际参数和范围以各批实现记录为准，并非列出的所有建议分支均已制作。

## 修改前的问题

AbilityController中除Rune外的八种基础武器共用Shoot；Burst、Spread、Count被合并成一次扇形齐射的数量。剑雨分支也复用角色位置发射，Spirit没有独立召唤物行为。回旋镖已有去返两段、符阵已有范围脉冲、飞剑已有绕身剑阵，应在已有差异上深化。

## 建议方向

| 武器 | 建议基础动作与节奏 | 建议分支，可同时获得 |
| --- | --- | --- |
| 手枪 | 短促点射、枪口闪光、后坐力；连射按时间分批，散射按角度展开 | 连射、散射、穿透、弹射 |
| 火球 | 蓄亮后抛出较慢火球，爆炸扩张，有清晰范围与残留火焰 | 连珠、爆裂、燃烧区域 |
| 飞剑 | 飞剑悬停、锁敌突刺并回返，剑锋与轨迹明确 | 追击飞剑、绕身剑阵、从目标上方落下的剑雨 |
| 灵体 | 持续存在的召唤物，自行追敌、扑击并返回玩家附近 | 召唤数量、攻击节奏、协同围攻 |
| 火炮 | 慢速抛物线炮弹、明显落点与爆炸冲击 | 多炮弹、分裂、持续轰炸 |
| 符阵 | 脚下展开阵纹，按节奏脉冲，强调范围和站位 | 扩张、多层脉冲、延迟爆符 |
| 回旋镖 | 弧线掠过敌群再回收，玩家走位影响回程轨迹 | 多镖、盘旋、去返两段伤害 |
| 弩 | 短暂拉弦后高速重箭，贯穿一条敌人，突出直线清理 | 重箭、多重弩矢、贯穿 |
| 冰杖 | 前方扇形寒气，逐步冻结，提供控制空隙 | 扇形扩张、冰环、冻结破碎 |

上述变化涉及射程、命中和伤害节奏，须与数值、升级依赖和现有任务兼容一起设计，不能仅换特效。保持无槽位限制、同武器分支共存和原有能力投入；逻辑命中与装饰效果分离，视觉预算不得移除真实伤害。

## 建议实施顺序

先做手枪、火球、飞剑三种起始武器，验证“短促射击、范围爆炸、御剑突刺”的对比，再扩展召唤、炮击、回旋和控场。实现时让AbilityController负责调度与共享数值，各武器行为负责轨迹、攻击阶段与命中；保持AssetService/PoolService资源所有权。实际落地与验证须另行记录。

## 本轮眨眼修复

CharacterAnimator原先用`(Time.time + GetInstanceID() * .137f) % 4.3f`计算眨眼周期。负实例ID会产生负相位，持续通过`blink < .16f`判断，造成不正常的高频开闭。已改为Mathf.Repeat保证非负相位，同时调整为每5.2秒一次、每次0.22秒。该共享修复适用于菜单与局内角色；不改变战斗受击/闪避表情。

`Tools/Build.ps1 -Mode Check`后台编译和330项现有编辑器检查通过，进程退出0；证据为Artifacts/Blink60Check.log和Artifacts/Blink60EditorChecks.json。本次没有重新构建Player、检查连续眨眼画面或实现武器方案，因此这些检查不构成眨眼视觉验收或武器行为验收。
