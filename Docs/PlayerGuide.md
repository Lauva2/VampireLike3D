# 万象远征 · 游玩说明

Windows x64，单人离线。解压整个游戏目录，双击 `WanXiangExpedition.exe`。不要单独移动 exe；同目录的 Data、MonoBleedingEdge、UnityPlayer.dll 和本地 AA 内容均需保留。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD | 移动 |
| Shift | 沿移动方向闪避，短暂无敌；无方向输入时沿上次方向 |
| E | 开箱、祭坛、营地或主动挑战 Boss |
| 右键敌人 / 空地 | 标记集火 / 取消标记 |
| 滚轮 | 镜头缩放 |
| Tab | 构筑界面，花费定向点学习与强化 |
| M | 探索地图 |
| Esc | 暂停、设置或主动撤离 |

攻击自动进行。所有体系都能混搭，同一武器的路线可以同时获得。升级时四选一，定向购买使用同一套成长内容。闪避有冷却，需要判断敌人的预警时机。

从林地启程，完成任务会解锁角色与升级选项。林地、荒漠、雪原、火山按 Boss 首胜顺序开放；这四位全部首胜后开放荧光菌沼、赤晶峡谷与包含六群系的混合地图。新增两群系各有专属敌人与可自愿挑战的 Boss。Boss 需要探索地标并主动交互开启；准备不足时可离开区域脱战，Boss 会恢复满血。击败 Boss 后可继续无限生存，也可主动撤离。

晶石用于局外永久成长。死亡和主动撤离都保留已获得的永久进度；同一局中已领取的地标奖励不会重复刷新。当前版本不支持关闭程序后续接同一局。

连弩擅长贯穿，可强化弹射与冰霜；回旋刃抛出后追随玩家返回，往返都能命中；寒霜法杖能范围冻结并强化碎冰。回旋刃需累计完成4次事件，寒霜法杖需累计冻结40次（既有火球冰霜路线也能推进）；具体进度见任务页。九种武器可同时持有，HUD能力栏可横向滚动查看。

## 存档与恢复

默认位置：`%USERPROFILE%\AppData\LocalLow\VampireLike\万象远征\profile-v1.json`。1.2.0使用存档格式2，沿用原文件名并自动迁移旧版永久进度。设置和永久进度保存在一起，原文件替换时保留 `.bak` 备份。主文件损坏时游戏尝试恢复备份，并在菜单提示。移动或恢复文件前请退出游戏，先备份现有文件。

可创建快捷方式并在目标末尾添加 `--portable`，改为将存档保存在游戏目录的 `Saves` 中；该目录需有写入权限。两种模式的存档互相独立。

## 设置与资源

设置中可调整音量、画质和全屏。低画质只调整表现，不删减已经获得的能力或伤害。游戏使用随包提供的 Addressables 内容，无需联网下载。

角色、场景、图标、特效和音频由项目制作流程生成；中文字体为 Noto Sans CJK SC，许可证见随包的 `Licenses`。实际测试结果与已知问题以交付版验证报告为准。
