# 首发内容与执行清单

工作名称：万象远征。名称可调整。目标平台：Windows x64，单人离线，中文界面。

## 冻结的首发范围

- 3 名角色：初始冒险者、任务解锁的元素学徒和御剑者。角色只改变起始能力和特性，不限制学习。
- 3 大体系、6 个首发小分支：元素/召唤、弹道/爆破、剑修/符阵。
- 6 个自动能力入口：火球、手枪、飞剑、灵体、爆破炮、符阵。前三个基础开放，后三个由任务解锁。
- 至少30个成长选项，覆盖原有15个草案选项、重复数值强化与新分支；3个特殊联动：雷电弹药、碎冰冲击、烈焰飞剑。
- 林地、荒漠、雪原、火山4种无限地图，四 Boss 首胜后开放混合地图。
- 4类普通敌人行为与精英变体，4个群系Boss，3类可探索事件（营地、宝箱、祭坛）。
- 随机升级、定向购买、无槽位限制、并行路线、任务解锁、永久属性、存档与设置。
- 主动Boss挑战、脱战缓冲/重置、自由撤离、死亡结算、继续无限生存。
- 正式明快Q版视觉、中文菜单/HUD/升级/技能树/任务/永久成长/设置/地图/结算、基础音乐音效。
- 存档覆盖永久进度、设置与纪录；1.0不包含中断后续接同一局，不将暂停菜单退出误称为局内续玩。

## 工作默认

- WASD移动，Shift沿移动方向闪避，无移动输入时沿最后移动方向；闪避穿敌不穿地形，攻击持续。
- E交互，Tab技能树，M地图，Esc暂停，右键标记/空地取消，滚轮镜头缩放。
- 首次任务完成后立即保存；新解锁可加入本局后续随机候选和定向树。
- 同一Boss地点本局击败后不重复领奖；继续探索可发现更远处新的挑战地点。
- 约25～30分钟为自然成长节奏；开发验证可使用独立诊断入口加速，不改变正式规则。
- 性能目标1080p/60 FPS，实际机器信息由Unity SystemInfo记录；压力与美术评审未执行前不标记通过。
