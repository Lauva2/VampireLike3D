## 1. 核心定位

- 类型：3D 俯视角、自动攻击的幸存者游戏。
- 核心体验：自由探索、逐步积累、跨体系组合、后期大规模战斗。
- 题材融合魔法、枪械、修仙等多个方向。
- 每个大方向包含多个小分支，后续可以继续扩展。
- 玩家局内可以完全自由混搭，不受职业或主修体系限制。
- 不设置武器槽上限或被动槽上限。
- 同一武器的小路线可以同时获得并叠加，不采用互斥路线。
- 新路线、进化或联动保留已有能力及其强化投入。
- 美术风格采用明快卡通的 3D 表现，整体色彩丰富、造型夸张、战斗氛围轻快。

## 2. 单局循环与节奏

选择角色与地图 → 探索和战斗 → 随机升级与定向购买 → 形成组合 → 完成任务与阶段挑战 → 自选撤离或继续生存 → 结算并推进永久成长。

### 成长节奏

采用逐步积累的节奏，约 25～30 分钟形成适合尝试一次完整阶段挑战的成长体验。该时间仅为暂定成长节奏参考，不是强制结束时间，也不会到点自动生成 Boss 追击玩家；Boss 由玩家探索发现并主动开启挑战。

| 阶段 | 体验与目标 |
| --- | --- |
| 开局 | 以初始武器开始战斗，较快获得前几次升级 |
| 前中期 | 获得其他体系的能力，探索地图，积累定向资源 |
| 中后期 | 深入强化已有能力，形成多路线叠加与跨体系联动 |
| 阶段挑战 | 挑战阶段 Boss，完成相关任务与地图进度 |
| 无限生存 | 自愿继续探索、成长，迎战持续增强的敌人与后续 Boss |

开局就应有清晰的攻击和成长反馈。前期的小成长与中后期改变攻击形态的大成长共同支撑体验。

### 撤离、死亡与结算

- 玩家从开局起可以主动撤离，结算已经获得的收获。
- 击败阶段 Boss 后提示选择撤离或继续，不自动结束本局。
- 选择继续后仍可主动撤离。
- 主动撤离保留已获得的永久资源、任务进度和解锁内容。
- 战斗死亡同样保留已获得的永久资源、累计任务进度和已完成的解锁。
- 击败阶段 Boss 后，当场记录通关与符合条件的解锁成果，后续死亡不撤销。
- 未完成的单局任务随本局结束而终止；累计任务保留进度。
- 继续生存的收益来自额外资源、更深入的构筑、挑战和生存纪录。

## 3. 局内成长

随机升级与定向购买共用同一套能力体系。

| 途径 | 获取方式 | 用途 |
| --- | --- | --- |
| 经验升级 | 击杀敌人、拾取经验 | 从随机候选中获得新能力、专属强化或通用被动 |
| 定向资源 | 稳定的阶段奖励，以及精英、事件等额外来源 | 在技能树中购买目标能力或强化 |

- 定向资源应有稳定来源，保证玩家每局有主动规划组合的机会。
- 局内定向资源用于本局，结束后重置。
- 技能树按大体系与小分支组织，支持跨体系购买。
- 基础能力可以直接获取，后续强化仅要求拥有其实际依赖的能力，不额外要求主修某个体系。
- 单人游戏打开技能树时暂停。
- 随机候选兼顾已有能力的强化与新能力。
- 购买所得能力也会被随机升级系统识别，后续可以出现对应强化。
- 价格依据能力本身的强度与等级制定，不因玩家已经持有很多武器而额外涨价。
- 基础强化可以重复获得；特殊机制首次获取与后续强化需要清晰区分。

## 4. 能力组织与组合规则

结构：大体系 → 小分支 → 具体能力、强化与联动。

| 大体系 | 小分支示例 |
| --- | --- |
| 魔法 | 元素、召唤、诅咒、奥术 |
| 枪械 | 弹道、爆破、工程、能量武器 |
| 修仙 | 剑修、雷法、炼体、符阵 |

首批内容以元素流、弹道流、剑修为切入点，其余分支后续扩展。

### 叠加与共享

- 攻击方式可以并行存在，例如追击飞剑、绕身剑阵与周期性剑雨同时运行。
- 通用强化通过标签确定适用对象，例如投射物、范围、召唤、持续伤害等。
- 专属强化只影响描述中指定的能力或类别。
- 每个升级选项都需要明确展示作用对象与效果，避免标签产生歧义。
- 普通混搭本身应当有效，特殊联动在此基础上增加新的战斗行为。
- 不要求为所有武器两两制作专属融合；优先建立可复用的组合规则，再制作部分特殊联动。
- 随机机会、资源分配和强化深度形成每局差异，不通过槽位上限或路线互斥限制组合。

## 5. 局外成长与任务解锁

### 永久成长

| 类型 | 内容与规则 |
| --- | --- |
| 永久属性 | 使用局外资源提升攻击、生命、移速、拾取范围、经验获取等 |
| 内容解锁 | 新角色、新升级选项，以及地图等内容通过特定任务解锁 |
| 角色特色 | 可以具有不同初始能力与特性，但允许学习所有体系 |

局外资源与局内定向资源分开。永久属性应有实际收益，局内的路线扩展和能力联动承担战斗规模扩大的主要作用。

角色专属成长的具体形式尚待确定，不作为首版已确定功能。

### 任务规则

- 基础玩法直接开放，确保第一局就能体验魔法、枪械与修仙的组合。
- 前期任务通过正常游玩自然完成，后期任务鼓励流派探索、组合尝试与特殊挑战。
- 任务通常不限制使用其他武器，例如飞剑击杀任务允许同时使用枪械。
- 明确区分累计任务和单局任务。
- 已完成的任务及时保存，任务条件与奖励可提前查看。
- 解锁依赖必须可达，不能要求玩家使用没有任何获取途径的未解锁能力。
- 新升级选项解锁后进入随机升级池与定向购买树，局内仍需选择或购买。
- 解锁代表获得获取资格，不代表永久携带本局能力或保留本局强化等级。

任务类型包括生存里程碑、流派运用、跨体系组合、Boss 挑战和地图事件。

## 6. 无限地图与群系

### 基础结构

- 地图随机生成，并可无限探索。
- 开局选择已经解锁的群系地图。
- 常规群系按顺序解锁，已解锁地图可以重复选择。
- 单群系地图以对应群系为主体，可以包含不同子区域、地貌与地标。
- 每局的地形、地标和事件分布变化；同一局返回已探索区域时，地形保持一致。
- 群系通过地形、敌人、事件、特殊地点和 Boss 形成差异。
- 已解锁的能力仍可在任意群系获得，群系不限制技能体系。

### 群系进度

地图主线通过首次击败当前群系 Boss，按顺序解锁下一群系。群系支线任务用于解锁角色、升级选项和特殊事件等内容，不要求全部完成才能推进地图；玩家可以之后返回补做。

首批群系按以下顺序展开，后续可以继续扩展：

| 顺序 | 群系 | 战斗与地形方向 |
| --- | --- | --- |
| 1 | 林地 | 突出怪群包围与清场 |
| 2 | 荒漠 | 突出开阔区域的追逐 |
| 3 | 雪原 | 突出地形绕行与路线选择 |
| 4 | 火山 | 突出具有预警的区域危险 |

林地初始开放；首次击败林地 Boss 解锁荒漠，首次击败荒漠 Boss 解锁雪原，首次击败雪原 Boss 解锁火山。

四个首批群系的 Boss 全部首次击败后，开放全群系混合地图。已解锁的单群系地图继续保留，可自由选择。

### 首批群系内容方向

以下为已认可的首批内容方向，具体布局、敌人参数和 Boss 招式细节留待设计与试玩调整。

| 群系 | 地形与探索 | 敌人特色 | Boss 方向 |
| --- | --- | --- | --- |
| 林地 | 林间空地、树丛通道、废弃营地 | 大量追击怪，少量快速包抄怪 | 古树守卫：树根预警、扇形横扫、召唤小怪 |
| 荒漠 | 沙丘、峡谷、绿洲、埋藏遗迹 | 高速追击、冲锋、远程投射 | 巨型沙虫：潜地移动、预警突袭、身体横扫 |
| 雪原 | 冰湖、冰脊、山口、冻结遗迹 | 远程攻击与近战包围配合 | 霜原巨兽：直线冲撞、冰锥、范围震击 |
| 火山 | 熔岩河、岩桥、玄武岩平台 | 精英与区域攻击组合 | 熔岩巨像：重砸、喷发、留下危险区域 |

- 各群系内部保留足够的开阔战斗区域，支持后期怪群聚集和大范围清场。
- Boss 的危险攻击提供明确预警，支持走位和无敌闪避应对。

### 全群系混合地图

- 单局中可以探索所有群系。
- 同一群系形成连续区域，群系之间通过地貌逐渐过渡。
- 不同方向可以通往不同群系，通过环境与地图提示帮助玩家判断。
- 群系分布、区域大小、地标和事件位置随本局随机生成。
- 沿用阶段挑战、自由撤离与无限生存规则。

### 探索内容

| 内容 | 作用 |
| --- | --- |
| 普通区域 | 战斗、经验获取和移动探索 |
| 精英营地 | 主动挑战，获取更多定向资源 |
| 遗迹、祭坛 | 事件、强化与任务进度 |
| 群系特殊地点 | 角色、升级选项等内容的任务条件 |
| Boss 地标 | 阶段挑战与群系解锁进度 |

高难度区域需要提前提示，让玩家主动选择是否挑战。无限生存中的敌人不仅提升数值，也通过敌群组合、强化精英和后续 Boss 增加变化。

### Boss 挑战方式

- 群系 Boss 位于探索发现的特殊地点，由玩家主动开启挑战。
- 玩家自行决定先继续探索、完善构筑，还是提前挑战 Boss。
- Boss 不因到达指定时间而强制出现并追击玩家。
- 全群系混合地图与继续生存后的 Boss 挑战沿用主动开启规则。
- 胜利后记录对应任务、通关与符合条件的解锁，并允许选择撤离或继续。
- Boss 战允许脱战，不通过封闭边界强制玩家留在战场。
- 玩家离开挑战区域后，Boss 脱战并恢复满血；玩家可以继续探索、完善构筑，之后返回重新挑战。
- 接近挑战区域边缘时显示提醒，离开后经过短暂缓冲再判定脱战，避免闪避短暂越界就意外重置 Boss；具体范围和缓冲时间待试玩调整。
- Boss 地点的发现提示、开启交互、脱战判定范围与时机，以及胜利后是否可重复挑战等规则尚待确定。
- 普通战斗中是否按时间投放精英波次，仍为建议，尚未定稿。

## 7. 首批能力与任务草案

以下为已讨论认可的首批方向，具体名称、参数、任务阈值和效果细节仍可调整。

| 选项 | 效果 | 解锁方向 |
| --- | --- | --- |
| 雷电弹药 | 枪械命中积蓄电荷，达到条件后触发雷击 | 同局拥有枪械与落雷并完成战斗目标 |

联动作为可叠加升级存在，保留原武器及其强化。任务只确定方向，尚未确定次数、时间、伤害量等数值。

## 8. 操作与闪避

### 已确认规则

- 使用 Shift 触发闪避，替代此前提出的空格键方案。
- 闪避带有短暂无敌时间，玩家需要把握时机躲避攻击。
- 闪避冷却、位移距离、动作时长和无敌窗口的起止与持续时间，留待原型试玩调整。
- 镜头固定朝向，跟随角色移动，支持滚轮缩放。
- 镜头不随角色转身旋转，不提供主动旋转操作；具体倾角、跟随手感和缩放范围留待原型调整。
- 武器默认自动索敌，允许玩家手动标记敌人以优先集火。
- 沿用本轮提出的右键标记操作；能够攻击到标记目标的武器优先攻击它，没有标记时照常自动索敌。
- 标记目标显示醒目的指示和血条。
- 标记只影响攻击优先级，角色移动始终由玩家控制，不因标记而自动追踪目标。

### 其余操作草案

前一轮提出的 PC 键鼠操作、WASD 移动、E 交互、自动拾取与各武器默认索敌偏好，仍作为讨论草案，尚未逐项定稿。闪避的方向、碰撞和攻击连续性，以及无敌窗口的视觉提示，也仍为建议。

### 手动标记规则

- 标记目标超出某武器射程或被障碍阻挡时，该武器暂时自动攻击其他可攻击目标，不追踪或移动角色。
- 标记目标重新可攻击时，适用武器恢复优先集火；目标死亡或不再有效时清除标记。
- 右键其他敌人切换标记，右键空地清除标记。
- 绕身剑阵、角色中心冰环等固定作用范围的能力保持原有行为。

## 11. 建议的原型验证顺序

完整工作流以 [DevelopmentWorkflow.md](DevelopmentWorkflow.md) 为准，以下仅概括玩法验证顺序，不代表功能已经实现。

1. 验证移动、俯视镜头、自动攻击、敌群追击与击杀反馈。
2. 接入三件基础武器、随机升级和定向购买，验证无槽位限制下的叠加体验。
3. 加入代表性路线与少量跨体系联动，验证组合和后期战斗表现。
4. 以一个群系验证无限生成、稳定回访、事件与探索收益。
5. 串联阶段 Boss、主动撤离、死亡结算与无限生存。
6. 加入永久属性、任务解锁与存档，再扩展群系和混合地图。
